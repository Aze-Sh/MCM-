# 图、网络流与路径（graph-flow-routing）

## 适用条件

对象可表示为节点、边、容量、代价、方向和时间，任务涉及最短路、流、覆盖、传播或调度。

## 不适用条件

欧氏距离不能代替真实网络；边权随时间/状态变化时不得直接套静态 Dijkstra。

## 数学定义

图 (G=(V,E))。最短路最小化路径边权和；网络流满足节点守恒和边容量；时间依赖路径的边代价取决于进入时刻。

## 假设

拓扑、方向、容量和权重语义正确；负权、时间 FIFO 性、多源合并等算法前提已检查。

## 输入输出

输入边表/邻接结构、源汇、容量、权重和事件函数；输出路径/流、总代价、守恒残差和可达性报告。

## 选模理由

先用 BFS/Dijkstra/最大流建立基线；只有边动态、随机或多目标时才扩展事件仿真、时间展开图或整数规划。

## Python 入口

`cumcm_py.graph.shortest_path_report(graph, source, target, weight="weight")`。

## MATLAB 入口

`cumcm.shortestPathReport(G, source, target)`。

## 验证方法

小图手算、节点守恒、路径逐边复算、断边/断点压力测试、动态路径逐段时间回放、与另一算法交叉验证。

## 失败模式

节点编号错位；无向/有向混淆；不连通未处理；动态边静态化；多源流重复计量；路径含未来不可通行边。

## 复杂度

Dijkstra 约 (O((V+E)\log V))；最大流依算法；时间展开和组合路径可能急剧增大。
