# 第五版：完成第2—4项改进

日期：2026-09-12。默认策略为 `joint-outcome-lookahead-v5`，原第四版保存于 `versions/v4`。本次没有运行或连接模拟器。

## 2. 调度考虑观测改变后续行动

旧版用相容区域的代表点估计是否顺路。新版比较立即处理、下一停靠点直接处理、下一停靠点先测向再处理三种条件成本界。

预测测向时，将全部可能输出分成至多12个完整角区间，再加入近距离与无信号分支；每个角区间用整体楔形约束构造后验，不用少数假想源位置代替全部响应。每轮对最多三个待处理源作较细前瞻。选中共享测向后，该源进入连续处理，防止无限等待。

共享阳性只在尚未开始局部收缩时建立新锚点，距离上界不超过1000米；已经消耗过收缩轮数的源禁止共享测向。因此没有通过反复换锚点重启五轮／六轮预算。

仍有边界：比较的是有限前瞻的保守计划界，没有证明多源整局最优或每次实际收益。

## 3. 保留非凸位置与方向关联

后验由最多48个“位置多边形＋该区域对应的方向区间”构成。阴性圆用内接多边形分割，保留两端或多块候选区域；每种方向分别约束其可能位置，避免将一个位置分支和另一个方向分支任意组合。

新阳性提高同一固定接收半径的下界，会重新触发旧阴性的距离比较；光学失败也立即排除20米内位置。分裂超过配额时保留父分区和原始记录，不丢掉尚未排除的世界。

仍有边界：角区间、排除圆近似和分区配额会留下保守薄层与分支；尚不是完整精确相容集。单次鲁棒清除可继续用位置并集的凸包，因为一个圆覆盖并集等价于覆盖其凸包；非凸信息主要用于条件观测及多圆覆盖。

## 4. 光学选择采用可证明的上下界门槛

新增有限多圆覆盖与顺序优化，允许分开的小区域由不同圆覆盖，最多三次尝试。每个连续凸单元都须被某个圆完整覆盖。

用于测向下界的位置必须满足所有历史物理条件，包括一个固定接收半径，以及能够同时解释阳性和距离内阴性的发射方向。不能把未经确认的外包顶点当作真实可能源来抬高下界。

任何先测向再清除本源的策略，至少需支付一次测向、一次成功清除，并到达该源的20米邻域。由此获得有效最坏成本下界。只有光学上界严格低于这个下界时才提前采用光学；带后续目标和单独完成清除两种比较均须通过。上下界重叠就保留测向。

失败后，把排除圆加入后验，再在剩余尝试数内重新规划；只有新剩余计划成本界下降时才替换原计划。

仍有边界：这是单源条件最坏成本比较，不是每个位置的逐实例优势；有限候选圆和有限见证也未求出所有连续方案的最优解。
