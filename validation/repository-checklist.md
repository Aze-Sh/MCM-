# 仓库最终验收清单

## 交付范围

- [x] 来源目录、阅读笔记、许可审计和分层证据
- [x] 2021–2025 年 25 道 A–E 真题问题卡与获奖特征综合
- [x] 13 个核心方法卡及问题类型选择框架
- [x] Python 库、MATLAB 镜像、共享夹具和跨语言比较器
- [x] 八阶段竞赛工作流与安全项目初始化器
- [x] 匿名论文、图表、引用和 AI 使用披露模板
- [x] 论文、引用、AI、代码和提交包检查器
- [x] 自包含 `cumcm-assistant` Skill
- [x] 覆盖矩阵与一键仓库验证

## 验收判定

最终判定以 `validation/repository-report.json` 为准。报告必须满足：

1. 所有必需验证组状态为 `passed`；
2. MATLAB 可用时必须实际运行单元测试、导出 13 个夹具并完成跨语言比较；不可用时只能标为 `skipped`，并引用 `environment/compatibility.md`；
3. XeLaTeX 可用时必须实际编译；
4. `git-policy` 输出为空；
5. 覆盖矩阵不存在 `missing` 状态或缺失证据文件；
6. 完整 `pytest` 运行零失败；
7. 最终提交后工作树为空。

## 非自动化边界

检查器只能验证客观格式和工程约束，不能证明模型正确、结论真实或论文达到获奖水平。正式提交前仍需三名队员逐问核对题意、数据来源、单位、数值、图表、引用、AI 记录和上传文件。
