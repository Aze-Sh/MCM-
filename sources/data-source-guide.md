# 数据源选择与审计指南

## 优先级

1. 题目附件和题目指定来源：先校验文件完整性、数据字典与单位。
2. 政府/国际组织/原始观测机构：国家统计局、世界银行、NASA 等。
3. 原始开放协作数据：OSM；必须说明覆盖偏差、查询与许可。
4. 聚合平台：Kaggle 只用于发现，尽量回到原始发布者。

| 来源 | 适合 | 访问与复现 | 关键风险 |
|---|---|---|---|
| 国家统计局 | 中国人口、经济、产业 | 动态网页；保存下载文件、指标页截图/说明与日期 | 指标口径、地区调整、现价/不变价、修订 |
| World Bank Indicators API | 跨国发展面板 | 保存完整 URL、indicator、country、date、source、原始 JSON | 聚合体混入、缺失、跨国可比性、历史修订 |
| NASA Open Data | 地球/航天观测 | 保存 dataset id、版本、处理级别、时空范围 | 分辨率、质量标志、单位、云/缺测、派生算法 |
| OSM/Overpass | 路网、POI、建筑、设施 | 保存 QL、bbox、日期、实例、原始响应；遵守 ODbL 署名 | 社区覆盖偏差、tag 不一致、超时导致不完整结果 |
| Kaggle | 第三方数据发现 | 记录数据集 slug、版本、许可并回源 | 来源不明、泄漏、过时、许可各异、需登录 |

## 每个数据集的最小审计记录

- 来源 URL、发布者、抓取时间、许可/署名要求、原始文件哈希。
- 每列含义、类型、单位、空间/时间粒度、缺失编码和有效范围。
- 行数、唯一键、重复、缺失率、异常值、时间连续性、坐标系。
- 清洗规则及删改行数；原始数据只读，处理数据由脚本生成。
- 与至少一个独立口径或统计总量进行数量级/汇总核对。
- 论文引用必须精确到数据集/指标，不只引用门户首页。

## 比赛现场的降级策略

- API 不稳定：使用赛前缓存的公开样例仅作代码测试；比赛结论只能使用允许且可说明来源的数据。
- 登录或付费受阻：立即换权威公开来源，不通过不明镜像绕过权限。
- 指标口径冲突：保留两套口径、解释差异并做敏感性分析，不静默挑选有利结果。
- 空间查询超时：缩小 bbox/分块查询，加入计数和去重，避免把中断误判成零对象。
