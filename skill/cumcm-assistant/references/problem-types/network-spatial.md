# 网络与空间类问题

## 识别信号

对象是节点—边、路线、覆盖、传播、空间布局或多主体通信。例：2022B/D、2023B、2025D。

## 快速基线

小图手算、BFS/Dijkstra、规则栅格覆盖、静态几何可视化和守恒检查。

## 候选模型

网络流、时间依赖最短路、覆盖路径、空间插值、计算几何、离散事件、任务分配。

## 数据要求

拓扑连通、坐标系、边方向、时间依赖、容量、空间分辨率、出现消失机制和事件顺序。

## 否决性假设

动态边被当静态；坐标距离代替真实路网；覆盖只看采样点；网络环路和多源合并未处理。

## 最低验证

小图手算、连通与守恒、路径逐边回放、网格/时间步收敛、边界覆盖、扰动拓扑稳定性。

## 适合图表

带方向网络、时空图、覆盖热图、路径时间线、流量守恒表、分辨率收敛图。
