# 评价与排序类问题

## 识别信号

要求重要性、综合评价、优先级、方案比较或政策效果。例：2021C 供应商、2024E 管控效果。

## 快速基线

单指标、等权标准化和业务规则三套排序并列，先看结论是否依赖权重。

## 候选模型

熵权/TOPSIS、AHP、PCA 得分、DEA、Pareto 支配、准实验；方法由评价对象和证据决定。

## 数据要求

指标方向、量纲、重复性、相关冗余、权重来源、对照组/干预时间、决策后果。

## 否决性假设

将高度相关指标重复计权；主观权重无专家流程；将综合分数解释为因果；政策前后没有对照。

## 最低验证

标准化方案对照、权重扰动、排名相关与翻转率、指标删除消融、外部结果或对照验证。

## 适合图表

指标相关热图、权重龙卷风、排名稳定图、Pareto 图、干预前后趋势与安慰剂图。
