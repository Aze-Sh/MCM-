# 工作流 4：实现与可复现计算

## 输入

选定模型、字段契约、验证计划、代码模板和结果清单。

## 输出

一条命令可运行的 Python/MATLAB 程序、测试、日志、随机种子、结果文件和环境说明。

## 步骤

1. 先写小算例或性质测试，再实现函数；返回命名结果，不返回无标签元组。
2. 路径一律相对项目根，输入只读，输出写 `output/figures`。
3. 所有随机过程显式种子；求解器保存状态、容差、gap 和最大违约量。
4. 自动导出结果与 `result-manifest.yaml`，杜绝手工抄数。
5. Python/MATLAB 共有方法用共享夹具对比结构、排名、可行性和数值容差。

## 停止条件

从空输出目录运行能重建正文所需结果，测试通过，关键结果可由独立公式/实现复算。

## 失败处理

测试失败按根因调试；依赖/工具箱缺失写成可操作错误或 skipped，不写成通过。

## 人工检查点

另一名队员在干净目录执行命令并核对至少三个正文数字和一张图。
