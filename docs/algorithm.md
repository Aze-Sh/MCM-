# 最终算法：v8快速版（已发布的r4）

最终程序采用 **20260912-shared-service-r4**。这是本文使用的v8快速版，保留对应的决策、几何、默认参数与停止条件。尚未证明接近连续原问题的理论最优，也不保证每场比v7节省500秒。

## 1. 代码阅读顺序

`run_robot.py → src/jammer_solver/solver.py`。

| 模块 | 作用 |
|---|---|
| `solver.py` | 搜索布局、路线和指派、清除投影、状态更新、RF与光学决策、执行与完成判断 |
| `exact_geometry.py` | 有理数裁剪、保守三角函数界、源域及连续覆盖核查 |
| `protocol.py` | 过程式HTTP请求、响应校验与明文日志 |
| `questions.py` | 第一、二题离线几何、候选域及解析界优化 |
| `tools/verification.py` | 离线证据回放、有限世界精确校准 |


主算法仍为过程式写法。`xin_zhuangtai`建立状态，`yunxing`推进整场，`xuan_dongzuo`选任务，`yuan_dongzuo`选源内动作，`zhixing_shijian`和`zhixing_yici`执行，`gengxin_jilu`仅根据真实返回更新账本，`huizong`输出摘要。

## 2. 搜索、定位和清除的主流程

20个频道分别维护未知、已发现、已清除或已排除状态。每次搜索逐一测量仍未知的频道，实际阳性建立该源的可行区域，实际阴性留在该频道记录中。

Q3使用原点和半径1125米的六点环，共7站。Q4使用原点、半径998米的8点内环、半径1868米的12点外环，外环起始角15度，共21站。Q4布局通过连续覆盖检查：对任意合法源位置，1000米内的测点围住它，使任意闭180度发射半平面至少包含一个测点。检查预算为20000节点、深度14；这不是网格采样过关就算全覆盖。

多源在同站被发现时，会比较共享第二观察点。候选在350米环上每30度一个，预计信息增益必须抵消测量和绕行费用。到达搜索点或清除点后，还会检查是否值得原地补测其它已发现源。实际没有收到信号时，不能伪造方位。

正观测按完整角度误差范围裁剪可行域；Q3额外使用半径1800米源圆域的保守外包约束。推进距离根据当前后验径向区间选择，不把已经排除的近距离区间重新纳入。Q4的阴性必须同时考虑半径与发射方向，不能沿用全向排除规则。已实际测过且都为阴性的同一点对不会无效重复。

当前已发现源和剩余搜索站放入同一任务排序。每个源有实际入口、预计服务费用及预计出口，比较多个完整初始顺序并做两轮单任务插入。选定一个源后通常处理到清除完成，再重新排序。出口与服务费用仍是近似，因此局部更优不保证整场更快。

## 3. 当前快速版对定向源的处理

共享第二测点和原地补测，会用该频道全部真实正、负观测估计候选位置能否收到信号。位置用剩余责任块的面积和代表点，半径1000～1500米按观测距离分段，朝向与真实观测一致的区间相交；发现前的阴性也参与评分。

对于一个源，以“估计接收概率 × 预计定位收益 − 6秒”筛选补测；一批共享测量的净收益还需抵消350米观察点的绕行费用。全向/定向各半、均匀半径和朝向是评分假设，题设没有给出这些分布。评分只用于选择实际动作，不作为排除未知源的证据。

当候选区域足够窄时，比较继续RF定位和2～8点完整光学排查链。候选链沿方位轴及其垂直方向构造，尝试多个访问顺序；若预计首次成功费用低于原RF乐观费用，就执行光学链的成功前缀。当前版本没有加入后续r5的“三种接收分支完整费用比较”和8秒切换余量。

对于静态源，同频道同位置的真实阴性点对不会无效重复。双阴性几何收缩和其它真实观测仍通过原证据逻辑执行。

## 4. 完成条件为什么没有被概率模型削弱

完整光学链由2～8点组成。通过有理数Voronoi裁剪，证明当前整个可行多边形被半径19.8米的清除圆覆盖，给题设20米留出余量。代表点只用于排序，不能代替连续覆盖证明。

概率与费用评分不写入实际观测账本。执行逐点调用真实清除接口，成功即停；失败则记录并更新责任。保留有限且不重置的试探额度、严格下降的完成秩、完整备用费用检查和备用路径。

结束前必须同时满足：所有已发现源均获得实际清除成功响应；剩余未知频道均被实际证据排除，或发现总数已达到16的题设上限。找到了10个、11个或14个都不能单独作为退出依据。

少于16个源的场景仍需证明其它频道不存在，因此全向多也可能比某些16源场更慢。已发现的大多数源像全向，不能证明未发现源是全向；Q4不能因此改用Q3七站覆盖。

## 5. 第一、二题

第一题把观测转换为前向楔形，判定可行域空、无界或有界；有界时计算顶点直径，并检查相应覆盖圆结论。区域直径D不保证存在半径D/2的覆盖圆，等边三角形即为反例。

第二题求可行第二测点区域，并对解析条带交的直径上界做有界优化：给定移动预算优化角度，或给定直径目标优化最小移动量。结果包含剩余上下界间隙，不能将解析判据最优误称为真实物理问题精确最优。
