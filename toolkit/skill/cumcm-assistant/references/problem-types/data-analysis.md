# 数据分析与识别类问题

## 识别信号

要求关系、分类、聚类、异常、重要因素或多源融合。例：2021B/E、2022C、2025C/E。

## 快速基线

数据字典和质量报告；可解释单变量/线性模型；多数类、逻辑回归、PCA/k-means 作为对照。

## 候选模型

广义/混合回归、树与核模型、聚类、降维、组成数据分析、特征融合、校准模型。

## 数据要求

样本主体、标签来源、缺失语义、重复测量、类别平衡、测量误差、可用外部验证。

## 否决性假设

主体或时间泄漏；把未检出当零；小样本高维无正则；训练集选特征后在同集报效果；相关冒充因果。

## 最低验证

管道内预处理、主体/时间正确切分、基线、混淆矩阵/残差、校准、重采样稳定性、消融。

## 适合图表

缺失图、分布与箱线、PCA 得分/载荷、混淆矩阵、ROC/PR、校准、特征稳定性。
