# 获奖特征人工复核表

本表用于赛前和交稿前的人工复核；创造性、逻辑闭环、领域合理性和文字说服力不得自动判定。检查器只能定位缺失、冲突和高风险模式，最终结论必须由团队人工复核。

## 任务与闭环

- [ ] 每问都有输入、输出、假设、方法、结果和验证。
- [ ] 后一问复用前一问时，状态与参数一致。
- [ ] 结论回答了题目，而不是只描述算法。

## 正确性

- [ ] 单位、坐标、符号和索引有统一表。
- [ ] 至少有一个手算、解析、极限或合成算例。
- [ ] 优化结果报告最大约束违约量并独立重算。
- [ ] 预测使用时间/主体正确的验证切分。

## 创新与必要性

- [ ] 创新针对一个明确的基线失败。
- [ ] 有消融或对照证明复杂度带来稳定增益。
- [ ] 没有用“首次、领先、显著提升”等无证据词。

## 表达与复现

- [ ] 摘要逐问量化回答。
- [ ] 每幅图只有一个主要信息并有单位、图例、注释。
- [ ] 代码、数据、随机种子和结果表映射清楚。
- [ ] 引用、AI 使用说明和支撑材料符合 2026 规则。

## 证据分级

- [ ] “官方评价”能定位到规则、讲评或颁奖词。
- [ ] “论文观察”能定位到官方展示论文页码。
- [ ] “分析推断”同时给官方标准与可观察依据，并允许反例。
