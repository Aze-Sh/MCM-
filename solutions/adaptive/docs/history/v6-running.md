# 第六版：由你操作模拟器

这两个启动文件只运行机器狗程序，模拟器始终由你手动打开。默认队号202612001024，默认第六版。

1. 先在模拟器选择**问题三演练**并开始测试，保留显示案例编码的界面。
2. 双击交付文件夹中的“开始问题三演练.cmd”，粘贴案例编码，确认题号和队号后输入 `CONNECT`。
3. 等待程序结束。输出在本完整项目的“运行结果”文件夹下新建的 `rehearsal_q3_日期时间` 目录中。保存程序生成的三个文件和你从模拟器导出的官方日志。
4. 将“官方观测信息_填写后放入运行目录.json”复制到该运行目录，改名为 `official_observation.json`；按界面或官方日志填写总源数、官方程序运行时间与官方日志原文件名。不知道的字段保留 `null`。字段中的时间单位是秒。
5. 问题三完成后，用相同办法选择**问题四演练**，双击“开始问题四演练.cmd”。
6. 把两个新运行目录的路径告诉我，我会整理实际结果并补论文。新版结果明确采用第六版标签，旧第三版演练仅保留作背景。

先各做一次演练。题面要求的问题三、四各三次正式测试，须在新版演练结果处理后进行；正式入口为“开始问题三正式.cmd”“开始问题四正式.cmd”，不要用演练入口记录正式测试。

需要关注的是：清除数量、完成与退出状态、总虚拟时间、移动时间、末次清除后的排除时间；官方程序运行时间单独取官方数据。本地进程耗时不替代它。不同案例间的时间差不能直接写成版本提速。

若程序报错，保留这一次的目录，不在同一个尚未结束的会话重复启动。把目录路径和界面情况告诉我即可。
