# 第七版：从真实瓶颈出发的算法改进

当前代码、25页论文和人工入口均已完成同步。以下说明区分算法已实现、数学比较范围和实际测量结果。

## 1. 把所有待办任务放入同一张图

第六版一个源与两批扫描绑定，导致问题三末批扫描时仍压着10个已知源。第七版将全部已知源及剩余扫描共同排序，每轮执行一个完整任务后更新，允许连续清除多个源。

每个处理模式使用实际第一测点作为入口，清除后的位置用整个可能区域表达。这样既消除虚构返回锚点的移动，又避免用估计中心低估源间路程。固定任务顺序内的模式选择由动态规划精确完成；任务顺序采用指派松弛、子环连接和有限搬移改进。旧计划补齐新任务后保留，新的选择不会比这个同任务旧计划的模型上界更差。

指派下界及选中计划的差距只衡量当前有限保守服务图。它不是实际整局最优性证书，也不包含未来尚未发现源的处理。

## 2. 让历史观测直接缩短核心定位

不再仅按“源距旧锚点最远多少”反复折半。对整个位置外包区域，求距离当前位置最近、又能保证到全部候选位置不超过指定收缩半径的测点。它来自一组圆盘的交集投影。

若旧距离界为L，新测点保证距离不超过0.502L−2.4，因此直接替换一次原核心测量。问题四还要求全部相容发射方向可见，不能证明就使用原成对测点。每源五次全向／十二次混合核心测量保证保留，不以重置轮数换取表面收敛。

## 3. 主动选择额外信息的位置

候选包括当前位置、最近保证接收位置及两类侧移位置。接收保证同时利用最小半径与同一源固定半径的历史耦合，而不一律局限于1000米。

正常示向按覆盖全部允许结果的连续区间评价，至多24段，并保留近距离与定向阴性。只有独立完成成本及带后续目标成本都改进超过1秒才采用；两项界来自同一个可执行延续。额外测量只在核心收缩前发生，随后立即处理完该源。

门槛严格可能导致不触发。真实首批观测的两例分析中均未接受额外信息，这一事实已经写入论文。

## 4. 光学终局利用“此前已经失败”

先失败的清除圆会排除相应位置。若某个后续点在条件残余区域内已经不可能成功，就跳过该尝试与绕路。至多三个圆心的不同顺序按条件首次成功成本评价。

失败后的改规划必须同时满足两项原剩余预算；光学替代仍要求成本上界低于测向优先策略的有效下界。这是单源条件最坏成本比较，不保证每个实际位置都更快。

## 5. 后期仍有覆盖修改机会

替换和删点分别保留提案名额。整局16次证明预算随搜索进度分阶段释放，避免前期失败提案耗光资源。每次改写仍须完整证明已访问点与新剩余点覆盖源域，扫描配额保持7／25。

## 6. 问题二将精度目标直接写入优化

在解析直径上界不超过163米的条件下，同时优化移动距离和角度。得到移动886.3433853米、前进651.5212558米、侧移600.9364774米。

计算下界886.2614456米，与可行设计相差0.081940米以内；这接近该解析判据下的最短移动。较第六版900米再减少13.6566米，解析精度相应放宽到163米。它不等于精确物理相容直径的极小极大最优。

## 已有证据

12项必要固定输入检查通过；没有连接模拟器、构造物理测试环境、算哈希或检查文件完整性。问题二进行了带预算的解析分支定界。论文已编译为25页，新增公式、表格与图示经过排版查看。

真实第六版演练：问题三清除13源、4889.664秒，问题四清除14源、8753.575秒。移动时间分别占85.07%、83.78%。官方总源数尚未提供，因此不报告独立确认的100%清除率。

## 仍然重要的限制

- 第七版尚未由用户运行模拟器，实际移动、清除效率与正式成绩未知。
- 模式和探测半径有限，未来未知源未入图，尚未求连续多源观测控制的全局最优。
- 定向可见性证明与响应外包可能太保守，主动信息或区域探测仍可能少触发。
- 联合分区48个上限及浮点工程余量会损失效率，尚无严格区间算术认证。
- 七点数目结论有特定静态条件；25点最少性、整局近似比与任意光学决策树最优性未证明。

本轮贡献在于针对题设把既有凸几何、指派、动态规划等工具连接成可执行且有成本约束的策略。没有全面文献排查，不能宣称学术首创已经确认，也不能把实现复杂度当作接近完美的证据。
