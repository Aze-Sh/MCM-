\section{支撑材料文件清单}

支撑材料至少包含以下内容：
\begin{enumerate}
  \item \texttt{code/}：问题一至四的完整可运行 Python 程序及依赖说明；
  \item \texttt{results/}：几何分析 JSON、合成压力测试结果和六次正式测试结果；
  \item \texttt{logs/}：问题三、四各三次正式测试由模拟器导出的原名日志；
  \item \texttt{figures/}：论文图的矢量 PDF 与高分辨率 PNG；
  \item \texttt{AI工具使用详情.pdf}：AI工具使用过程、采纳、修改和人工核验记录。
\end{enumerate}

当前版本为正式测试前工作稿，正式日志与正式结果尚未生成，最终打包时将据真实文件更新本清单。
